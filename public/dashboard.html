Getting started

No logs yet. Connect a source and they’ll stream in here.

Logbase receives events through collectors. Create one, point your app at its endpoint, and every event becomes searchable within seconds.

  1. 1
    Create a collectorPick HTTP or UDP, an auth method and a payload format.
  2. 2
    Send a test eventCopy the ready-made curl command, or use the built-in Test button.
  3. 3
    Search and filterEvents appear here with live tail, level filters and full-text search.
What an event looks like
[
  {
    "timestamp": "2026-10-15T08:32:17Z",
    "level": "error",
    "app": "checkout-api",
    "message": "Payment gateway timeout"
  }
]

level, app and message power the filters. Any extra fields are kept and searchable.

Collectors

Each collector is an ingestion endpoint with its own transport, authentication and payload format. Pause one at any time without losing its settings.
